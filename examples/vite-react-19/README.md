# Vite + React 19 Starter (`@abeta.dev/*`, Zero-Tailwind Setup)

Minimal runnable Vite + React 19 starter demonstrating the modular `@abeta.dev/*` ecosystem **without configuring Tailwind CSS**:

- **Zero-Tailwind styling** via precompiled `import "@abeta.dev/ui/style.css";` in `src/main.tsx`.
- **Core UI primitives** (`Button`, `Card`, `Badge`) from `@abeta.dev/ui`.
- **India FinTech components** (`AmountSummaryCardIndia`, `UpiQrCard`) from `@abeta.dev/india/react`.
- **Talent & verification components** (`CheckpointRunner`, `ProofOfWorkCertificate`) from `@abeta.dev/talent`.

## Quick Start

```bash
npm install
npm run dev
```

Open the local Vite URL (default [http://localhost:5173](http://localhost:5173)) in your browser.
