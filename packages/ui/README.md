# @abeta.dev/ui

Accessible, high-performance React 19 UI component primitives built with Tailwind CSS v4 and Radix UI.

## Installation

```bash
npm install @abeta.dev/ui
```

## Usage

```tsx
import { Button } from "@abeta.dev/ui/button";

export default function App() {
  return <Button>Click me</Button>;
}
```
